Practice environment

Conveyor holding circuit and permissives

Apply an IF–THEN rule as PLC data and ladder instructions. The exercise separates the physical buttons, stored bits, contact tests, rung results, coil writes and output commands.

Physical inputA push button or field device changes an electrical input signal.
Contact instructionReads a stored Boolean tag and returns TRUE or FALSE.
Ordinary coilWrites the current rung result to a Boolean tag on every scan.
Output commandMOTOR_RUN = 1 commands the output; it does not prove the motor is rotating.
Control-logic training boundary

This exercise teaches ordinary PLC logic and positive healthy-state tags. Real emergency-stop and guard functions require a properly engineered safety circuit, safety relay or safety PLC. Do not treat this rung as a complete machine-safety design.
