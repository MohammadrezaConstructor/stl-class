PLC · Sequential control

Control a mixing tank

An operator presses Start to make one batch. Two inlet valves, A and B, fill the tank. Once it is full, the mixer runs for 30 seconds. Outlet C then drains the tank. When it is empty, the machine waits for a new press of Start.

The four IF–THEN rules

Each rule starts with the current step. The tank can be empty during filling, but only an empty tank during draining ends the batch.
