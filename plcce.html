PLC Tank Process — Sequential IF–THEN Logic

Read the problem, see how it is written as four IF–THEN rules, then change the conditions and watch how the outputs follow the rules.

1The problem

Let us consider a simple tank system. The system has two inlet pipes, A and B, which fill the tank with two different liquids. There is a motor that mixes the liquids inside the tank. There is also an outlet pipe, C, which drains the mixture after mixing is complete.

The process begins when the operator presses the start switchR1. When the process starts, valves A and B openR1 so that the two liquids can enter the tank. A level switch detects when the tank has reached the desired level. Once the tank is fullR2, valves A and B close, and the motor starts mixingR2.

The motor runs for a fixed time, for example 30 seconds. When this time is completeR3, the motor stops and valve C opensR3 to drain the tank. When the tank is emptyR4, valve C closesR4, and the system is ready for the next cycle.

This example helps us understand how a PLC controls a sequence of operations. The PLC does not only turn one device on or off. It controls a process step by step.

yellow = a condition (becomes an IF) green = an action (becomes a THEN) R1–R4 = the rule it becomes

2From the problem to IF–THEN rules

Every rule the PLC uses has the same two parts:

IF — the conditionSomething the PLC can check, whose answer is only TRUE or FALSE: is the start switch pressed? Is the tank full? Are the 30 seconds over?
THEN — the actionWhat the PLC does to the outputs when the condition is TRUE: open or close a valve, start or stop the motor.
Conditions come from the inputs (what the PLC reads)
  • Start switch — pressed or not
  • Level switch — tank full or not
  • Tank empty — yes or no
  • The PLC's own 30-second timer — over or not
Actions go to the outputs (what the PLC drives)
  • Valve A — open or closed
  • Valve B — open or closed
  • Mixing motor — running or stopped
  • Valve C — open or closed

The rules are used one after the other: Rule 1 → Rule 2 → Rule 3 → Rule 4 → back to Rule 1. The PLC remembers which step the process is in (Idle, Filling, Mixing or Draining), so it knows which rule comes next.
