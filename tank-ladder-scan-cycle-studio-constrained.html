Source boundary and teaching assumptions The course slides specify the behavior: fill through A and B, mix for 30 seconds, drain through C, stop at any point, select the desired level, and optionally keep the motor on during evacuation. This simulator uses internal stage bits to make that sequence visible. It also exposes a separate TANK_EMPTY feedback bit because one high-level switch alone cannot distinguish a partly full tank from an empty tank.

Known process rules

These are recalled from Session 6; the new work is translating them into ladder logic.

Rule recall
1 · FillWhen the Start switch is active and the tank is ready, activate solenoids A and B.
2 · MixWhen the desired level is reached, deactivate A and B, run the motor, and start a 30-second timer.
3 · DrainWhen 30 seconds is reached, open solenoid C. The motor normally stops unless Switch Button 3 is selected.
4 · RepeatWhen the tank is empty, close C and return to filling while the Start switch remains active.
Extension controlsStop Button 1 stops the process; Button 2 requests the selected liquid level; Button 3 keeps the motor on during evacuation.
