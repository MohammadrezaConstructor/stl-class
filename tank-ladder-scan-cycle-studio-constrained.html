    What you should already know
    • Session 6 tank rules: fill through A and B, mix for 30 s, drain through C, then repeat.
    • Bit: a stored value that is 0 (FALSE) or 1 (TRUE).
    • N.O. contact is TRUE when its bit is 1. N.C. contact is TRUE when its bit is 0.
    • Series = AND, parallel = OR. A rung is TRUE when a path of TRUE instructions joins the two rails.
    • Coil: writes its rung result (1 or 0) to a bit.

    Basic mode: complete one manual READ–SOLVE–UPDATE scan and answer the four base predictions. Button 2, Button 3 and automatic run remain locked.

    BASIC MODE
    Extension controls unlock only after the manual scan and the base prediction set are complete.
    Source boundary and teaching assumptions The course slides specify the behavior: fill through A and B, mix for 30 seconds, drain through C, stop at any point, select the desired level, and optionally keep the motor on during evacuation. This simulator uses internal stage bits to make that sequence visible. It also exposes a separate TANK_EMPTY feedback bit because one high-level switch alone cannot distinguish a partly full tank from an empty tank.

            Glossary

            Question: what exactly does each PLC term on this page mean? (Click to open.)
            PLC
            Programmable logic controller: an industrial computer that repeatedly reads its inputs, solves its program and writes its outputs.
            Scan (scan cycle)
            One pass of READ → SOLVE → UPDATE. A real PLC repeats it every few milliseconds; here you can step it by hand.
            READ (input scan)
            Copies the state of every physical input into the input image.
            SOLVE (program execution)
            Evaluates the rungs from top to bottom, using the input image and memory bits, and writes memory and output-image bits.
            UPDATE (output scan)
            Copies the output image to the output module, which switches the valves and the motor.
            Input image
            Memory that holds the input values captured at the last READ. Contacts test these stored bits, not the wires.
            Output image
            Memory that holds the command bits written by coils. These bits reach the devices only at UPDATE.
            Input / output module
            Hardware that connects field wiring to the PLC: the input module senses switch voltages; the output module energizes solenoids and contactors.
            Tag
            A named PLC variable, such as START_SW or PA_CMD.
            Bit
            A value that is 0 (FALSE) or 1 (TRUE).
            Maintained switch
            Stays where you leave it (the Start switch and Button 3 here).
            Momentary push button
            Is 1 only while it is pressed (Stop Button 1 and Button 2 here).
            N.O. contact –| |–
            Normally open contact: an instruction that is TRUE when its bit is 1.
            N.C. contact –|/|–
            Normally closed contact: an instruction that is TRUE when its bit is 0. It tests memory; it says nothing about how the field device is wired.
            Series / parallel
            Instructions in series must all be TRUE (AND). In a parallel branch, any one TRUE path is enough (OR).
            Rung
            One line of ladder logic between the power rails: conditions on the left, one output instruction on the right.
            Power rails
            The vertical lines at the left and right of the ladder. Green highlighting means logically TRUE, not electrical current.
            Ordinary coil –( )–
            Writes the rung result to its bit on every scan: 1 while the rung is TRUE, 0 as soon as it is FALSE.
            SET / RESET
            Write 1 (SET) or 0 (RESET) only when their rung is TRUE. Otherwise the bit keeps its value, so it acts as memory.
            Stage (step) bit
            A memory bit that is 1 while the sequence is in that stage: STEP_FILL, STEP_MIX or STEP_DRAIN.
            Transition (MOVE STAGE)
            A rung that clears the current stage bit and sets the next one when its condition is TRUE.
            CYCLE_ACTIVE
            Memory bit that records that the cycle is allowed to run. R1 sets it; R0 clears it.
            TON (on-delay timer)
            IEC 61131-3 timer. Q becomes 1 once IN has been 1 continuously for PT. If IN becomes 0, ET and Q reset to 0.
            IN
            The timer's enable input. Here it is STEP_MIX.
            PT (preset time)
            The target time: 30 s for MIX_TIMER.
            ET (elapsed time)
            How long IN has been 1, capped at PT. Remaining time = PT − ET.
            Q
            Timer output bit: 1 when ET has reached PT.
            Command vs feedback
            A command bit (PA_CMD) is what the PLC asks for. A feedback bit (LEVEL_HIGH, TANK_EMPTY) is what a sensor reports. A command does not prove that the device moved.
            Solenoid valve
            An electrically operated valve. A and B fill the tank; C drains it.
            Late input
            An input that changes after READ. The current SOLVE cannot see it; the next READ copies it only if it is still present.
