Keep these PLC words separate
Physical deviceA real sensor, switch, motor or valve installed on the machine.
Bit and tagA bit stores 0 or 1. A tag is the meaningful name used to identify that data.
ConditionA requirement that can be true or false, such as “the guard is closed.”
Contact instructionSoftware that reads a Boolean bit and returns a true-or-false test result.
Rung resultThe final true-or-false answer obtained after the PLC evaluates the rung.
Coil instructionSoftware that writes the rung result to a Boolean bit. It is not automatically the physical motor or valve.
