Total closeness rating (TCR)

Numerical values: A=6, E=5, I=4, O=3, U=2, X=1. TCRᵢ = Σⱼ value(relᵢⱼ). CORELAP enters departments in decreasing TCR priority.

How the three algorithms differ
  • CORELAP — construction; qualitative (REL chart); deterministic; places dept with highest TCR first, then grows the layout outward by placement rating.
  • ALDEP — construction; qualitative; random first department, then requires a minimum closeness with the previous entry; fills a serpentine sweep; run many times, keep the best adjacency score.
  • CRAFT — improvement; quantitative (from–to flow matrix); starts from an existing layout and applies the best pairwise exchange until no swap reduces load·distance.

Theory: the CORELAP procedure
  1. Compute TCRᵢ = Σⱼ v(relᵢⱼ) with A=6…X=1. The department with the highest TCR enters first, at the center.
  2. Next entry: the department with the strongest relationship (A, then E, then I…) to any already-selected department; ties broken by higher TCR.
  3. Placement: evaluate every empty cell touching the layout. PR = Σ v(rel) × 1 (edge) or × 0.5 (corner) over adjacent placed departments. Place at the highest PR (ties: closest to the layout's centroid).

Candidate cells appear with their PR during each placement step — ask students to predict the winner before clicking Next.

ALDEP — Automated Layout Design Program

Placed0 / 0
Adjacency score—
Best of trials—
Theory: the ALDEP procedure
  1. Select the first department at random.
  2. Scan the REL chart for an unplaced department whose relationship with the last entered department meets the minimum acceptable level (here: strongest qualifying one wins). If none qualifies, pick at random.
  3. Fill the building in a vertical serpentine sweep of the chosen width, allocating each department its area in consecutive cells.
  4. Score adjacency: A=64 · E=16 · I=4 · O=1 · U=0 · X=−1024 for each pair of departments sharing an edge. Because step 1–2 involve chance, ALDEP is run many times and the best layout kept.

Theory: the CRAFT procedure
  1. Start from any complete layout and a quantitative flow matrix.
  2. Cost: TC = Σᵢⱼ fᵢⱼ · dᵢⱼ with rectilinear centroid distances.
  3. Each iteration, estimate the cost change of every pairwise exchange, apply the best improving swap, and repeat until no exchange reduces cost — a local optimum (different starts can end differently: try several random initial layouts!).
