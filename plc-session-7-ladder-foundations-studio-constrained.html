PLC 7 · Ladder programming bench

Student guide · start here
  1. Predict. Read the problem and follow a rung from left to right. Decide which input change should turn its output ON or OFF.
  2. Try one change. Stay in Hold, change an input switch in the I/O monitor, then click Step one scan. Compare Field with PLC, the teal path and the machine. On a small screen, switch between Ladder and Field I/O.
  3. Experiment. Select a contact or coil, choose its type and tag, then Apply edit and step again. Open Edit rung layout to add series or parallel contacts and extra rungs. Change one thing at a time.
  4. Check and explain. Try the exercise below. Test both ON and OFF inputs, and describe why the output changed. Run reference cases compares the original problem with your program; deliberate experiments can produce FAIL results. Watch M_A yourself when practising with this extra memory bit.

Starting again. Reset I/O resets inputs, memory and timer and scans your current program once. Restore reference restores the selected program; then use Reset I/O for a fresh trial. Run repeats scans; Hold freezes the last scan.

Contact and coil quick reference
Bit state and contact result
ON/OFF is the tag value. TRUE/FALSE is the contact test. A TRUE contact passes the path only when the upstream path reaches it.
NO and NC
A normally open (NO) contact is TRUE when its tag is ON. A normally closed (NC) contact is TRUE when its tag is OFF. These instructions test a PLC bit.
Series and parallel
Series requires every test in that path (AND). Parallel needs at least one passing branch (OR).
P and N edge contacts
P is TRUE for one scan on an OFF → ON change; N on an ON → OFF change. This bench starts each contact’s previous sample OFF after reset or a tag/type change.
Ordinary, SET and RESET coils
An ordinary coil writes the path result every scan. A TRUE path makes SET write ON and RESET write OFF. With a FALSE path, SET and RESET leave the bit as it was. Rungs run top to bottom; the last instruction that writes a tag determines its final value.
TON timer
ET is elapsed time; Q is the done bit. The first enabled scan starts ET at 0. Later manual steps add one second. Q turns ON at the preset; a FALSE timer input clears ET and Q.
