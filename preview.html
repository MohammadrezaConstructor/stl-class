Student guide · start here
  1. Predict. Start with the reference program and Step by phase. Which valves should open when Start turns ON?
  2. Try one scan. Turn on Start switch in Field I/O. Run READ and compare Field with Sampled. Run SOLVE and inspect the teal ladder paths and output Commands. Run UPDATE and watch the devices.
  3. Change one instruction. After UPDATE, select a contact or coil, open Edit this instruction, choose its type or tag and apply. Predict the difference, then repeat a scan. The diagram updates at SOLVE.
  4. Compare. Try Start OFF or Stop ON and explain the result. Reset tank restarts the process with your edits. Restore reference program and reset tank also removes your edits.

On a small screen, switch between Ladder and Field I/O. Choose a Network to inspect another group of rungs. Run to next stage advances complete scans.

Contact and coil reminder
  • NO tests for an ON bit. NC (slashed) tests for an OFF bit. TRUE describes the test, so an OFF bit can make an NC contact TRUE.
  • Series means AND. All tests must pass. Parallel means OR. One passing branch is enough. Teal wires trace the connected true path from the left rail.
  • An ordinary coil writes the path result each SOLVE. SET writes ON on a true path, and RESET writes OFF. On a false path, SET and RESET leave the bit alone.
  • Rungs run from top to bottom. If several instructions write the same bit, the last write wins. The device receives its final command at UPDATE.
  • TON counts while its input is true. Here it sets its done bit after 30 simulated seconds. A false input resets it.
