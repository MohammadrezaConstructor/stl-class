    What you should already know
    • The Session 6 tank rules: fill through A and B, mix for 30 s, drain through C, then repeat.
    • Bit: a stored value that is either 0 or 1.
    • N.O. / N.C. contact: a software test. N.O. asks “is the bit 1?”; N.C. asks “is the bit 0?”.
    • SET / RESET: SET writes 1 and RESET writes 0, but only on a scan when the rung is TRUE. Otherwise the bit keeps its value.
    • TON: Q turns 1 after IN has stayed 1 for the preset time PT. ET shows how much of PT has elapsed.

      A prediction counts once you have answered it correctly. If you answer wrongly, you can read the explanation and try again. Unlocking adds Button 2, Button 3, automatic run and prediction 3.
      Source boundary and teaching assumptions The course slides specify the behavior: fill through A and B, mix for 30 seconds, drain through C, stop at any point, select the desired level, and optionally keep the motor on during evacuation. This simulator implements the corrected stage-memory sequence. RUN_OK pauses the outputs without erasing the active stage. A separate TANK_EMPTY feedback bit is included because one high-level switch alone cannot distinguish a partly full tank from an empty tank.

      Question: which things are physical devices, and which are PLC data and instructions?

      Beginner bridge
      Physical deviceA switch, sensor, solenoid, or motor on the real machine.
      Stored PLC valueA bit such as LEVEL_HIGH or PA_CMD containing 0 or 1.
      Contact instructionReads a stored bit and returns true or false.
      Coil or function instructionWrites a bit, updates stage memory, or updates timer data.
      Command is not proofMOTOR_CMD = 1 means the PLC is commanding the motor ON. It does not prove that the motor turns. Only a feedback sensor could prove that, and this tank has feedback only for the level.

      How time works here: each Advance step first lets process time pass under the outputs of the last scan. During that time the level and MIX_TIMER change. Then one complete READ–SOLVE–UPDATE scan runs. Switches and buttons trigger a scan immediately, without any process time passing. A real PLC scans every few milliseconds; here one scan stands for one process second.
